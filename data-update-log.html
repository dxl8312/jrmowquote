Filling rules

  1. No backfilling. If a pre-project collection or update has a genuine record it may be attached; otherwise recording starts from the first real update.
  2. Verifiable sources. Every numeric change has a source or is explicitly marked as a modelling assumption.
  3. Consistent with the pages. Log entries match the current wording of the Methodology page.
  4. Corrections marked separately. An error correction writes Correction in the Reason field so readers can identify it.
  5. Estimates labelled. Changes involving an estimate write estimate in Data changed so it is not read as a measured value.
